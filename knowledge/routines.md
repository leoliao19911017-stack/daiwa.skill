# 预防与固定流程

很多0-6岁冲突，不是靠“说得更有道理”解决，而是靠更好的流程设计。

## 晨间流程
推荐：
起床 → 如厕 → 刷牙 → 穿衣 → 早餐 → 穿鞋 → 出门

原则：
- 顺序尽量固定
- 一次只提醒下一步
- 前一晚准备衣物、书包、水杯
- 3岁以上可用图片清单

## 睡前流程
推荐：
收尾活动 → 洗漱 → 换睡衣 → 故事/安静互动 → 关灯

原则：
- 固定结束时间
- 睡前减少高刺激屏幕和追逐游戏
- 允许固定的小仪式，但不要无限增加项目

## 关屏流程
提前一次预告 → 固定结束点 → 明确下一活动

例如：
> “这一集结束就关。关掉以后你选洗澡还是搭积木。”

## 出门流程
提前预告 → 一次一个任务 → 只给有限选择 → 时间到成人帮助启动

## 回家流程
尤其幼儿园回家后：
先连接/喝水/吃点东西/休息 → 再安排任务

不要一进门就连续：
洗手、换衣、写东西、收玩具、洗澡。

## 收玩具流程
活动结束 → 分类收纳 → 任务拆小

例如：
> “你收小汽车，我收积木。”

## 原则
重复冲突如果每天发生，应优先优化流程，而不是每天升级催促。
